# Online Order Processing — Facade Pattern

A simple Java application demonstrating the **Facade Structural Design Pattern**.

The `OrderFacade` coordinates inventory, payment, shipping, and notification services through a single `placeOrder()` method.

**Features:**
- Order processing
- Inventory management
- Payment validation
- Shipping and notifications
- Rollback on failed operations

**Technologies:** Java, OOP, Facade Design Pattern.

Run `Main.java` to test different order scenarios.
